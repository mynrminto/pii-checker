# 個人情報チェッカー（ブラウザ完結版）

外部サービスに貼る前のテキストに、個人を特定しうる情報・要配慮個人情報が含まれていないかを
**利用者のブラウザ内だけで**判定し、安全な形への書き換え案と変更理由を示す静的サイト。
サーバーは存在せず、入力テキストはどこにも送信・保存されない。広告・アクセス解析なし。

> 本ツールはスクリーニングであり、安全性や法令適合を保証するものではない。

## 設計原則：必要十分な最低限の匿名化
個人を特定できなくするために必要な部分だけを削り、知りたい内容は最大限残す。

| 扱い | 対象 |
|---|---|
| 残す | 疾患・検査・治療・薬剤名（稀少疾患も）、年代、性別、症状と経過の論理 |
| 一般化 | 正確な年齢→年代、年月日→基準日からの相対表記（間隔は保つ）、極端な値→幅 |
| 削る | 氏名・ID・連絡先、市町村以下の地名、施設名、学校・職業など識別に直結し臨床的意味が薄いもの |

稀少疾患・届出疾患は「特異な記述」になりうるが、疾患名そのものは残し、地域・正確な年齢・時期の側を削って組合せを断つ。

## 仕組み
| 層 | 実装 | 動く端末 |
|---|---|---|
| 機械検出 | `rules.js` 正規表現（マイナンバー、電話、住所、生年月日、カルテ番号、氏名表記…） | すべて |
| 資料検索 | `rag.js` 文字バイグラム BM25。`docs/*.md` を見出し単位でチャンク化 | すべて |
| AI判定 | WebLLM（WebGPU）で Qwen2.5 1.5B/3B をブラウザ実行。短い判定（verdict＋所見）と、リスト未収載の疾患名の希少性推定のみ | WebGPU 対応ブラウザ＋PC級端末 |

AI判定が使えない端末でも機械検出・書き換え・資料検索は動く。
書き換えと変更理由はすべてルール層（`rules.js`）が決定論的に生成する。小型モデルによる「AI一般化」は検証の結果（質問に回答してしまう／一字も変えない）価値がなく、公開版からは外した。大型モデルを使える医局内ローカル版では LLM 主体の一般化が有効。
機械検出で high が出たら、モデルが ok と言っても caution に引き上げる（安全側）。

## 「送っていない」ことの可視化
- 上部のバナーに、判定中に発生した外部通信の件数をリアルタイム表示（PerformanceObserver）。0 件のままが正常
- オフライン検知：Wi-Fi を切っても動作することを表示
- DevTools の Network タブで利用者自身が確認できる手順を記載

## 公開手順（GitHub Pages）
```bash
git init && git add . && git commit -m "init"
gh repo create pii-checker --public --source=. --push
gh api -X POST repos/{owner}/pii-checker/pages -f build_type=legacy -f source[branch]=main -f source[path]=/
```
数分で `https://<owner>.github.io/pii-checker/` で公開される。`index.html` 内の GitHub リンク（`#repo`, `#repo2`）を自分のリポジトリ URL に書き換えること。
Cloudflare Pages / Netlify でも「ビルドなし・ルートを公開」でそのまま動く。

WebLLM は `https://esm.run/@mlc-ai/web-llm` から読み込み、モデル本体は Hugging Face からブラウザの Cache Storage に保存される。
完全に自己ホストしたい場合は `npm i @mlc-ai/web-llm` して bundler で同梱し、モデルファイルも自サイトに置けばよい。

## 資料の追加
`docs/` の2ファイルは個人情報保護法の定義と医療分野の匿名化実務を自前で要約したもの。
原典（法令全文＝著作権対象外、個情委・厚労省ガイダンス＝政府標準利用規約で再利用可）をテキスト化して `docs/` に置き、`docs/index.json` にファイル名を追加する。見出し（`#`）を残すと検索精度が上がる。

## 既知の限界
- 1.5B〜3B のモデルは見落とし・過検出がある。正規表現層が下支えするが最終判断は人が行う
- 敬称なしの氏名は正規表現で拾えない。改善するなら transformers.js で日本語 NER を足す
- スマホでは AI判定は重い（機械検出・資料検索のみ推奨）
- 書き換え案は医学的内容を変えない指示をしているが、必ず原文と突き合わせて確認する
