# 個人情報保護法の基本用語（要約・自前整理）

このファイルは判定の土台となる定義を簡潔にまとめたもの。条文そのものは e-Gov から `docs/` に追加すること（README 参照）。

## 個人情報（法2条1項）
生存する個人に関する情報で、次のいずれかに当たるもの。
- 氏名、生年月日その他の記述等により特定の個人を識別できるもの。
  他の情報と容易に照合でき、それにより個人を識別できるものを含む（容易照合性）。
- 個人識別符号が含まれるもの。

ポイント: 単独では識別できなくても、手元の他の情報と組み合わせれば特定できる場合は個人情報に当たる。

## 個人識別符号（法2条2項）
- 身体の特徴をコンピュータ用に変換した符号: DNA塩基配列、顔認識データ、虹彩、声紋、歩容、静脈、指紋・掌紋
- 個人に割り当てられる番号: マイナンバー、旅券番号、運転免許証番号、基礎年金番号、健康保険の被保険者等記号・番号・保険者番号、住民票コード、在留カード番号 など

## 要配慮個人情報（法2条3項）
本人に対する不当な差別・偏見が生じないよう特に配慮を要する情報。
- 人種、信条、社会的身分
- 病歴（過去・現在の疾患）
- 犯罪の経歴、犯罪により害を被った事実
- 身体障害・知的障害・精神障害等があること
- 健康診断等の結果、診療・調剤情報（医師等が行った検査・診療・指導・調剤の事実や内容）
- 刑事事件・少年保護事件の手続が行われたこと
取得には原則として本人の同意が必要（法20条2項）。オプトアウトによる第三者提供は不可。

## 仮名加工情報・匿名加工情報
- 仮名加工情報（法2条5項）: 他の情報と照合しない限り特定の個人を識別できないよう加工したもの。氏名等の削除、個人識別符号の削除、財産的被害につながる記述の削除。内部利用が前提で、第三者提供は原則不可。
- 匿名加工情報（法2条6項）: 特定の個人を識別できず、元の個人情報を復元できないよう加工したもの。特異な記述（例: 極めて稀な疾患、110歳など）の削除・一般化が必要。

## 判定の実務的な目安
- 氏名、連絡先、個人識別符号、顔写真が含まれる → 個人情報に該当（危険）
- 病歴・診断名・検査結果が個人と結びつく形で含まれる → 要配慮個人情報（危険）
- 年齢・性別・居住地域・職業・入院日などが複数組み合わさる → 容易照合性により特定されうる（注意）
- 統計値や一般的知識のみ → 該当なし
