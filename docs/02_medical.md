# 医療・介護分野における個人情報の取扱いと匿名化の実務（要約・自前整理）

出典として参照すべき原典: 個人情報保護委員会・厚生労働省「医療・介護関係事業者における個人情報の適切な取扱いのためのガイダンス」、厚労省「医療情報システムの安全管理に関するガイドライン」、日本医学会・日本小児科学会等の症例報告における患者情報保護に関する指針。原典は README の手順で `docs/` に追加する。

## 医療情報の位置づけ
- 診療録、処方箋、検査結果、画像、看護記録、紹介状などは、患者個人が識別できる限り個人情報であり、同時に要配慮個人情報に当たる。
- 死者の情報は法の直接対象外だが、遺族の個人情報に当たる場合やガイダンス上は同様の配慮が求められる。
- 外部のクラウドサービスへ患者情報を入力することは、第三者提供または委託に当たりうる。委託先の安全管理措置が確認できないサービスへの入力は避ける。

## 症例報告・学会発表で求められる匿名化の目安
- 氏名、イニシャル、カルテ番号、患者ID: 削除
- 生年月日、受診日・入院日・手術日などの正確な日付: 削除または相対表記（「入院3日目」「発症から2週間後」）
- 年齢: 10歳刻みなどの年代に（乳幼児・小児では「○か月」「○歳」も特定につながることがあるため、必要最小限に）
- 住所: 都道府県より細かい地名は削除。施設名も特定につながれば削除
- 職業、学校名、家族構成、民族・国籍: 診療上不可欠でなければ削除
- 稀な疾患・稀な経過・極端な数値: 一般化するか、同意を得る
- 顔写真・体表写真: 目や特徴的部位をマスク。それでも特定されうる場合は同意が必要
- 画像のDICOMヘッダ、文書のメタデータ、スクリーンショット内の氏名表示: 見落としやすいので確認

## 組み合わせによる再識別リスク
単独では無害に見える項目でも、以下が複数そろうと特定されうる。
- 年齢（特に正確な月齢）＋性別＋居住市町村
- 受診日＋施設名＋疾患名
- 職業＋勤務先規模＋疾患
- 家族の情報（きょうだいの年齢や人数）＋地域
小規模な集団（離島、小さな町、稀少疾患患者会など）ではより少ない項目で特定される。

## 外部AIサービスへ入力してよい情報の例
- 患者と切り離された一般的な医学的質問
- 上記の匿名化を済ませ、本人・施設・日付が特定できない症例要約
- 統計値、公開されている論文の内容
